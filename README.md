# QA Automation
Repositorio dedicado a las prácticas realizadas para el taller de **QA Automation**. <br>
Todos los contenidos prácticos y resoluciones están estructurados en **Jupyter Notebooks (`.ipynb`)**.


## Tecnologías y Herramientas
- **Lenguaje:** Python 3.14
- **Entorno de ejecución:** Jupyter Notebook
- **Testing:** `pytest`
